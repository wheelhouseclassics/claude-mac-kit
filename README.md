# claude-mac-kit

One line on a fresh Mac (Apple Silicon, current macOS, admin account):

```bash
curl -fsSL https://raw.githubusercontent.com/wheelhouseclassics/claude-mac-kit/v1.0.0/install.sh | bash
```

installs Homebrew, Node, git, gh, Claude Code, Claude Desktop, Obsidian, Tailscale, a curated set of Claude Code
plugins / skills / hooks / commands (`manifest.json`), a global `CLAUDE.md`, and a second-brain vault skeleton.
Then `claude-kit setup` walks through every key and login, and `claude-kit doctor` proves each integration works.

Repository layout:

- `install.sh` — bash 3.2 bootstrap (the one-liner)
- `manifest.json` — the curated contract, GENERATED by `scripts/build-manifest.js` (see `manifest.schema.json`)
- `kit/` — everything that lands on the Mac: skills, commands, hooks, pipeline, `CLAUDE.md`, vault skeleton, `DROPPED.md`
- `cli/` — `claude-kit install | setup | doctor | airtable-init | bench-teardown` (Node >= 22.13, zero dependencies)
- `scripts/` — build-machine tools (manifest builder, publish, git hooks)
- `test/` — `node --test "test/*.test.js"`

Secrets never touch this repo: gitleaks runs as a pre-commit hook (`scripts/install-git-hooks.sh`) and as a GitHub Action.
